# PrimeVue 4 disabled popup reproductions

Uses the Vite and Aura setup from PrimeVue's issue template. Run `npm install` and `npm run dev`, or open the StackBlitz preview.

- **AutoComplete**: click the timer button, then open suggestions with the arrow before the timer expires. Once the input is disabled, click Orange. The value changes and the update count increments.
- **ColorPicker**: click the timer button, open the swatch, then press and hold in the color field before the timer expires. After the readout says Disabled, move the mouse while holding it. The value and update count keep changing.
